# admin-panel (заготовка)

Отдельная админка/CRM для оператора: список заказов, назначение курьеров, управление каталогом, рассылки.

Варианты реализации (выбрать позже):
- Отдельный бот в MAX для сотрудников (проще всего запустить на старте)
- Веб-панель (React-админка поверх тех же эндпоинтов `backend/app/api/routes/admin.py`)
- Готовое no-code решение (Retool, NocoDB) поверх той же БД — для быстрого MVP
